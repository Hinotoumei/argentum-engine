# Persist verification

Persist has a native MH2 implementation and verified gameplay. This record ships with its commit on Hinotoumei/argentum-engine, focused-magic. Five other packet identities remain; this is not full-task completion or deployment evidence.

The script returns the chosen nonlegendary creature from its caster's graveyard using movement-scoped battlefield entry counters. The reusable `CardDestination.WithEntryCounters` wraps a battlefield destination with nonnegative fixed counter counts. Counters are applied before entry tracking/events, honor counter prohibitions and doubling, and survive saved Aura host-choice continuations. Aura movement now follows the standard zone transition and removes attachment when entry is redirected. The SDK language reference is updated in the same change.

All 15 dedicated Persist scenarios pass: actual casting and saved stack state, entry-trigger power, lethal entry, prevention, doubling, redirected entry, target removal in response, independently retargeted copies with saved decisions, four illegal target classes, and unaffordable atomic rejection. Nine supporting SDK/movement/Aura checks also pass. The final focused gate after alternate-printing artist corrections passed in 6m13s, with compiled snapshot/round-trip/lint checks. See persist-targeted-results.json. MH2 snapshot review shows only the Persist addition; the preexisting FUT line-ending change is excluded.

The full sequential build passed in 1h24m5s: 19,677 passed, 24 skipped, zero failures/errors across 20 modules. Only the accepted mtgish-only exclusion was used. Unchanged tasks may reuse valid Gradle results. This full run preceded two alternate-printing artist display-string corrections; final focused verification covers those corrections. See persist-full-build-results.json for the exact scope.
