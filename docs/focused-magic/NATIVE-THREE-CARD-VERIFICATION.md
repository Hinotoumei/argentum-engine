# Barrowgoyf, Engineered Explosives, and Surgical Extraction

The three native definitions have 41 passing dedicated gameplay scenarios: Barrowgoyf 14, Engineered Explosives 14, and Surgical Extraction 13. The targeted gate also passed compiled-card snapshots, JSON round-trip checks, and card lint. Snapshot review found only the intended additions to 5DN and NPH, plus Barrowgoyf in the new incomplete M3C scaffold; FUT has no semantic change. The scaffold is excluded from sealed play. See `native-three-card-test-results.json`; earlier incremental scenario records remain preserved.

Barrowgoyf counts distinct types across both graveyards in every zone, including the stack. Its combat-damage trigger preserves lifelink, has independent optional mill/creature-return choices, uses the actual damage amount, cannot return a milled card redirected out of the graveyard, and survives its source leaving in response. Cases exercise casting/payment rejection, deathtouch combat, short/empty libraries, irrelevant damage, and complete saved-game continuation at both choices.

Engineered Explosives counts distinct colors actually spent rather than X. Its destruction reads charge counters captured when its source is sacrificed as the activation cost. Scenarios cover same/different colors, colorless spending, X=0, both-player destruction, lands surviving, actual Clue creation, counter changes, doubled entry counters, indestructibility, and atomic unaffordable actions.

Surgical Extraction rejects basic lands and accepts nonbasic lands. It privately searches the targeted card owner's graveyard, hand, and library before filtering optional selections by name. The caster may select none, some, or all copies; the captured owner shuffles even if no card is selected. Cases cover mana and Phyrexian life payment, insufficient-life rejection, both players' zones, hidden nonmatching cards, shuffle secrecy, saved-game continuation, and a target removed by a real response before resolution.

Fresh set-qualified Scryfall checks match Oracle text, canonical metadata, image URLs, and every official ruling against the compiled definitions; images returned HTTP 200. Earliest-printing and scaffolded-reprint checks passed. See `native-three-card-metadata-verification.json`. Barrowgoyf's ordinary printing is M3C 102; M3C 50 is the extended-art variant.
